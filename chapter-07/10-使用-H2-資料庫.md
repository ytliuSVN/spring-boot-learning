# 單元 10 - 使用 H2 資料庫

## H2 資料庫

- H2 是一種嵌入式資料庫
- 用途：可以在啟動 Spring Boot 時被生成出來，在運行結束時被銷毀，用完即丟
- 常用在單元測試，降低程式對實體資料庫的依賴
    - 任何一台電腦，不需要安裝任何軟體，都可以運行該單元測試

在 pom.xml 加入 H2 驅動

```xml
<!-- Source: https://mvnrepository.com/artifact/com.h2database/h2 -->
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <version>2.4.240</version>
    <scope>test</scope>
</dependency>
```

設定 H2 資料庫連線資訊

src/test/resources/application.properties

```properties
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.url=jdbc:h2:mem:testdb
spring.datasource.username=sa
spring.datasource.password=sa

spring.jpa.hibernate.ddl-auto=none
```

### 在 H2 資料庫中創建 `student` table

Spring Boot 預設會找 schema.sql 與 data.sql

創建 TABLE 的 SQL 一定要放在 schema.sql 的檔案裡面

src/test/resources/schema.sql

```sql
CREATE TABLE IF NOT EXISTS student (
     id INT PRIMARY KEY AUTO_INCREMENT,
     name VARCHAR(30),
     score DOUBLE,
     graduate BOOLEAN,
     create_date TIMESTAMP
);
```

插入數據相關的 SQL 一定要放在 data.sql 的檔案裡面

src/test/resources/data.sql

```sql
INSERT INTO student (name, score, graduate, create_date) VALUES ('Amy', 90.3, true, '2021-09-01 10:20:33');
INSERT INTO student (name, score, graduate, create_date) VALUES ('Rom', 34.6, false, '2021-08-10 17:21:14');

```
