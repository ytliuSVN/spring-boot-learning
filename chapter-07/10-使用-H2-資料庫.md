# 單元 10 - 使用 H2 資料庫

## H2 資料庫

- H2 是一種嵌入式資料庫
- 用途：可以在啟動 Spring Boot 時被生成出來，在運行結束時被銷毀，用完即丟

## 使用 H2 資料庫的運作流程

```mermaid
flowchart LR

    Step3["3. 創建 H2 資料庫<br/>🗄️ H2 資料庫"]
    Step4["4. 執行 @Test 單元測試"]

    Step1 --> Step2
    Step2 --> Step3
    Step3 <-->|"5. 存取 H2 資料庫的數據"| Step4
```
