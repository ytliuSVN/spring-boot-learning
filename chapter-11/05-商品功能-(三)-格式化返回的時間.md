# 單元 5 - 商品功能（三）- 格式化返回的時間

設定時區返回是 GMT+8

application.properties

```markdown
spring.jackson.time-zone=GMT+8
spring.jackson.date-format=yyyy-MM-dd HH:mm:ss
```

### 時間戳（Timestamp）

- 是一個整數
- 計算從 UTC 1970 1/1 00:00:00 開始的總秒數
    - UTC = GMT+0 = 英國格林威治時間
- 不論在哪個時區，全世界所有人的 Timestamp 都會是同一個值
- 在 Java 中，可以使用 `System.currentTimeMillis()` 取得當前 Timestamp
